# 숫자 구슬 추첨

교사가 숫자 범위와 뽑을 개수를 정하면, 투명한 추첨기에서 숫자 구슬이 하나씩 뽑혀 나오는 학급용 추첨 앱입니다.

## 사용 방법

1. `index.html`을 더블클릭해 브라우저(크롬, 엣지, 웨일)로 엽니다.
2. 시작 숫자, 끝 숫자, 뽑을 개수를 정합니다.
3. 뽑는 방식을 고릅니다.
   - 자동: 버튼 한 번에 끝까지 차례로 뽑습니다.
   - 한 개씩: 버튼을 누를 때마다 하나씩 뽑습니다.
   - 속도: 빠르게를 고르면 연출이 절반 시간으로 줄어듭니다.
4. 추첨 시작을 누릅니다. 스페이스바, 엔터, 오른쪽 화살표, 발표용 리모컨의 다음 버튼으로도 뽑을 수 있습니다.
5. 다시 하기를 누르면 처음 상태로 돌아갑니다.

같은 추첨 안에서 이미 나온 숫자는 다시 나오지 않습니다.
설정은 이 브라우저에만 저장되며, 어떤 정보도 외부로 보내지 않습니다.

## 배포 (GitHub Pages)

빌드 과정이 없습니다. 이 폴더의 파일을 GitHub 저장소에 그대로 올리고,
저장소 Settings > Pages에서 main 브랜치를 선택하면 됩니다.
